Roblox Username Availability Checker

Generates short usernames and checks them one at a time. The checker stops when it finds an available username.
Ready
Start the local server, then press Start checking.
This version uses a small local server so the browser does not call Roblox directly from a content:// page. It does not create accounts, collect passwords, or bypass Roblox protections. If Roblox rate-limits the server, the checker stops and tells you to wait rather than trying to bypass the limit.
